## Principio documental

- La implementación y las pruebas tienen prioridad sobre este texto.
- La documentación distingue almacenamiento local de transferencias externas: memoria, embeddings y telemetría se almacenan en el dispositivo; el proveedor LLM configurado y las integraciones activadas pueden recibir el contenido estrictamente necesario para ejecutar una tarea.
- Las afirmaciones dependientes de plataforma, configuración o fallback deben conservar esos calificadores.
